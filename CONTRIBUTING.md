# Contributing to Trillion Trader

First off, thank you for considering contributing to Trillion Trader! It's people like you that make Trillion Trader such a great tool for the community.

## Where do I go from here?

If you've noticed a bug or have a feature request, make one! It's generally best if you get confirmation of your bug or approval for your feature request this way before starting to code.

## Fork & create a branch

If this is something you think you can fix, then fork Trillion Trader and create a branch with a descriptive name.

## Implement your fix or feature

At this point, you're ready to make your changes. Feel free to ask for help; everyone is a beginner at first.

## Code Standards
- We use React 19 + TypeScript for the frontend.
- We use Java 21 + Spring Boot 3 for the backend.
- Ensure all code is properly formatted (e.g. `npm run lint` for the frontend).
- Do not commit any secrets or `.env` files.

## Make a Pull Request

At this point, you should switch back to your master branch and make sure it's up to date with Trillion Trader's master branch.
Once your branch is up to date, you're ready to make a pull request.
