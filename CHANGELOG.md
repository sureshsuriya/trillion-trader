# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-30
### Added
- Complete React 19 / Vite frontend with TailwindCSS.
- Admin Dashboard with CMS for Blogs, Prop Firms, Brokers, Resources, Testimonials, and FAQs.
- Spring Boot 3 Java 21 backend with JWT authentication and MongoDB integration.
- Production readiness: SEO (Helmet Async, sitemap, robots), code-splitting.
- Deployment templates: `render.yaml`, `vercel.json`, and Dockerfile.
